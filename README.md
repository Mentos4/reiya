# REI REJOIN Roblox Account Manager - Terminal Edition

Single standalone CLI script for Termux & Android VPhone / Emulators with auto-join, per-package game setup, window tiling, home-screen recovery, and live dashboard monitoring.

## 🚀 One-Line Run & Update Command (Termux / Android)

Run this command in Termux to fetch the latest version and start immediately:

```bash
rm -f ~/reiya_terminal.py && curl -sL "https://raw.githubusercontent.com/Mentos4/reiya/main/reiya_terminal.py?t=$(date +%s)" -o ~/reiya_terminal.py && python ~/reiya_terminal.py
```

## ✨ Core Features

- **Per-Package Game Mapping**: Configure `Roblox 1` to auto-join Blox Fruits, `Roblox 2` to auto-join Pet Simulator 99, etc.
- **Direct Place / PS Link Join**: Instant direct game launch bypassing home screens.
- **Live Terminal Dashboard**: Live stats, status indicators, and game tracking per instance.
- **Auto Window Tiling**: Auto-arrange Roblox windows on side-by-side stack or grid.
- **Discord Webhook Updates**: Status updates with live screenshot attachments.
